venv:
זהו מקום מבודד שבו מותקנות ספריות הפייתון שלי למשל
Fastapi






פרומט לייצירת קובץ bash:


צור קובץ bash בשם run.sh שמטרתו להפעיל אפליקציית python קיימת הפרויקט שלי.
פעל לפי המפרט הבא:

הגדר את סביבת ההרצה כך שהקובץ יופעל באמצעות bash דרך מנגנון איתור הנתיב של מערכת
ההפעלה.
2. הגדר סקריפט לעצור מיד כאשר הפעולה נכשלת.
3. בתחילת ההרצה, העבר את סביבת העבודה לתיקייה בשבה נמצא קובץ הסקריפט עצמו, ללא תלות תלות בתקייה שממנה המשתמש הפעיל אותו.
4. בדוק אם בתיקייה הפרויקט נמצא תיקייה בשם venv.
5. אם התיקייה אינה קיימת, הצג הודעה בעיברית המציינת שנוצרה סביבה וירטואלית ולאחר מכן צור אותה באמצעות python 3 עם מודול venv.
אם התיקייה קיימת, דלג על יצירת סביבת העבודה הוירטואלית והמשך לשלב הבא.
7. הצג הודעה בעיברית המציינת שהספריות מותקנות.
8. התקן את התלויות המוגדרות בקובץ requirements.txt באמצעות מנהל החבילות שנמצא בתוך הסביבה הוירטואלית, תשתמש באפשרות התקנה שקטה, כדי לצמצם את הפלט המוצג בטרמינל.
9. הצג הודעה בעיברית המציינת שהשרת עולה בכתובת המקומית - http://locallhost:8000 ושתמיד יהיה אפשר לעצור באמצעות control + c
10. הפעל את שרת uvicorn - מתוך הסביבה הוירטואלית תוך שימוש היישום app.app:app הגדר את השרת להאזין על כל ממשקי השרת...
11. שמור על סדר הפעולות המתואר לעיל ועל ההודעות שהמשתמש כותב.
12. אל תוסיף דברים שלא ביקשתי ממך תהיה מדוייק פרקטי לפי ההנחיות.
13. אל תשנה שמות של תיקיות או קבצים או את הנתיבים.

דרישות לפלט:
החזר קובץ bash שלם ומוכן לשימוש 
הצג את כל התוכן של run.sh בתוך בלוק קוד יחיד
אל תציג הסברים או חלופות או שיפורים לקבצים
הקפד שהקוד שיווצר יממש את כל הדרישות בדיוק, ללא השמטות
